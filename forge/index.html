Welcome to Forge

Forge runs entirely in your browser. Your clients, drafts, prospects and payments are stored on your device — nothing is shared with anyone, and nothing belongs to anyone else.

To unlock everything, connect your own accounts in Settings:

  1. 1PayPal Client ID — from your PayPal Developer Dashboard, so clients can pay you through PayPal checkout. Forge only ever uses your Client ID (never a secret) and only talks to paypal.com.
  2. 2Google OAuth Client ID — from your Google Cloud Console (create an OAuth client with this site's URL as an authorized origin/redirect). Lets you back up drafts and payments to your own Google Drive.
  3. 3Gemini API key (optional) — from Google AI Studio, for one-click AI draft generation. Without it, the built-in template composer still works great.

Where does the Google OAuth Client ID come from?

In the Google Cloud Console, create a project, enable the Google Drive API, then create an OAuth 2.0 Client ID (type: Web application). Add this page's URL as an Authorized JavaScript origin. Paste the Client ID into Settings. Forge only ever sends your token to googleapis.com.

Back up to Drive

Files are saved as JSON inside a “Forge” folder in your Drive.

Where do I find this? — step-by-step setup
  1. Go to developer.paypal.com and log in with your PayPal account (a free business account works fine).
  2. At the top of the dashboard, flip the toggle from Sandbox to Live.
  3. Open Apps & Credentials, then click Create App.
  4. Name it something like Forge and click Create App.
  5. On the app page, copy the Client ID (the long string of letters and numbers). You do not need the Secret — Forge never asks for it.
  6. Paste the Client ID into the box above and hit Save settings. Done — you can now collect payments through PayPal checkout.
Where do I find this? — step-by-step setup
  1. Go to console.cloud.google.com and log in with your Google account.
  2. Click the project dropdown at the very top → New Project. Name it something like Forge, click Create, then select it.
  3. In the left menu, go to APIs & Services → Credentials.
  4. Click Create Credentials → OAuth client ID. First time only: Google asks you to configure the consent screen — choose External, fill in the app name and your email, and save.
  5. Set Application type to Web application and name it Forge.
  6. Under Authorized JavaScript origins, click Add URI and type exactly:
    https://sdotbill.github.io
  7. Click Create. A popup shows your Client ID (it ends in .apps.googleusercontent.com) — copy it.
  8. Paste it into the box above and hit Save settings. Done — Forge can now back up your drafts and payments to your own Google Drive.
Where do I find this? — step-by-step setup
  1. Go to aistudio.google.com and log in with your Google account.
  2. Click Get API Key in the left menu.
  3. Click Create API key. If it asks for a project, let it create a new one.
  4. Copy the key (it starts with AIza).
  5. Paste it into the box above and hit Save settings. Done — one-click AI draft generation is now on. It's free within generous limits; without it, the built-in template composer still works.
