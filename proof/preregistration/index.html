What is being demonstrated

An exolex is a personal artificial intelligence that one person owns: it carries its owner's whole record in memory from one working session to the next, it holds tools (a computer, a browser, accounts) so it can act and not only talk, and it works under a verification discipline — claims are graded against pre-registered lines and the underlying record, and anything that is not in the record is answered as not in the record, never invented. A conventional chat session with a large language model does the opposite on each point: it opens with no memory of earlier sessions, it holds no tools of its own, and when its knowledge runs out it produces a fluent answer anyway.

Each demonstration below is a task any reader can repeat against the same public and company sources. "The register" means the company's own record files, named per probe.
